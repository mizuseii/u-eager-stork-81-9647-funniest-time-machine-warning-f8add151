A one-line warning label for a time machine: if you see yourself boarding, do not board — two of you voids the warranty, and only one of you gets home.

## Run it

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the output directory for local runs).
